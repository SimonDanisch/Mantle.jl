## 3. Patterns that inflate the code

Each pattern: name, examples, estimated line cost in these files.

**P1. Branching on a kind by hand instead of dispatch** (api.md rule 2 forbids Symbol kinds). `copy_buffer!(direction::Symbol, …)` branches on `:upload`/`:download` four times (memory.jl:1248, 1252, 1267, 1275) after asserting the Symbol (1234); `AllocFailure.op::Symbol` tracked by reassignment through a `try` block (memory.jl:331, 548, 579, 581, 585) and read at 341; `VulkanCompiledGraphicsPipeline.front::Symbol` (coretypes.jl:233); device kind as Symbol (device.jl:1987-1990); `src isa VkManagedBuffer ? src.buffer : src` twice in one function (command.jl:1385-1386, 1391-1392); `c isa VkContext` on a field declared `::Any` (memory.jl:645, 679, 689; coretypes.jl:87). Cost: ~120.

**P2. Defensive checks on values whose type is known.** Ten accessors take `ctx::Union{Nothing,VkContext} = VK_CONTEXT_REF[]` and start with `ctx === nothing && return` (device.jl:2201-2202, 2286-2288, 2296-2298, 2306-2308, 2315-2317, 2329); `diagnostics.jl:23-71` tests `ctx === nothing` twelve times in two functions; `throw_with_validation_context` tests `bq === nothing` six times (command.jl:1404-1428); `isdefined(ctx, :pipeline_cache)` on a struct whose constructor sets it (pipeline_cache.jl:134); `validate_launch_args` wraps a field read in `try`/`catch` and checks a state byte (launch.jl:49-65); `pack_arg_assert_live` (launch.jl:295-302); `seal!` is idempotent and is still guarded at its callers (command.jl:210, 253, 310); `bq === nothing && return` (memory.jl:811); `o.open` and `rec.open` flags that exist so a pooled buffer can be told apart from a written one (device.jl:75, 118; command.jl:306-310). Cost: ~180.

**P3. `try`/`catch` that swallows or only logs.** Violations of the owner's rule (no rethrow, no report beyond a log): device.jl:1809-1821 (coopmat property query fails → `@warn`, "treating as unsupported"); device.jl:2378-2385 (`vulkan_available` turns two error types into `false`); memory.jl:747-755 (destructor failure → `safe_fin_log`); pipeline_cache.jl:76-81, 107-124, 117-122, 135-158, 172-183 (five, each warn-and-continue; the one at 172-183 swallows inside `atexit`); command.jl:1201-1206 (binds the exception to `cur`, then tests `cur isa Integer` at 1214). Catches that re-dispatch on a string: pipeline.jl:472-503 matches `"PIPELINE_COMPILE_REQUIRED"` in `sprint(showerror, e)` and retries. Catches that are core's job: memory.jl:1142-1148 and 1160-1172 (OOM → collect/drain/retry), memory.jl:550-605 (one `try` around five Vulkan calls with a Symbol tracking which one). Cost: ~150.

**P4. Globals.** Module-level mutable state in these files (api.md:524 allows `REGISTRY` only): `VK_CONTEXT_REF` (device.jl:819), `LIVE_CONTEXTS` (848), `VK_CONTEXT_LOCK` (881), `VK_CONTEXT_COUNTER` (922), `LAYER_SETTING_STORAGE` (2234, grows for the process life), `_PIPELINE_CACHE_ATEXIT_REGISTERED` (pipeline_cache.jl:167), `PIPELINE_THREAD_CFUNC` (pipeline.jl:43), `PIPELINE_NO_COMPILE` (122), `PIPELINE_COMPILES_REFUSED` (125), `PIPELINE_COMPILE_MISSES` (128), `MAX_PIPELINE_CACHE_SIZE` (187), `TIMESTAMP_POOL_SIZE` (profiling.jl:164), `PIPELINE_EXEC_PROPERTIES_REQUESTED` (440). ## 4. What the design docs miss

**G1. Hardware video decode.** api.md:205 lists a `VideoDecodeNode` but sections 2-4 and Appendix A contain no verb, no session type, and no row for the names in `BACKEND_VOCABULARY` (`videodecodes`, `decode_h264_gpu`, `h264decoder`, `feed!`, `decodemore!`, `remaining`, backend.jl:815; hooks declared at runtime/backendhooks.jl:68-128).
