# Mantle.jl

Mantle is a Julia library for recording and running GPU compute and graphics
work across device backends.

- The [API guide](api-guide.md) introduces the target API for device arrays,
  graph recording, and resource ownership.
- The [API contracts](api.md) and [execution contracts](execution-contracts.md)
  describe the intended behavior and backend responsibilities.
- The [recording plan](recording-plan.md) and [refactor ledger](refactor-ledger.md)
  track implementation and validation.

The [Julia examples](examples.jl) illustrate the target API as pseudocode.
